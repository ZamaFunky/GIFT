# Flores Amarillas App 🌻

Proyecto Flask con flores amarillas animadas únicas para regalo especial.

## Instalación

1. Entra al directorio:
   ```
   cd flores_amarillas_app
   ```

2. Crea entorno virtual (Python 3):
   ```
   python -m venv venv
   ```

3. Activa entorno:
   - Windows: `venv\Scripts\activate`
   - Luego instala dependencias:
     ```
     pip install -r requirements.txt
     ```

4. Ejecuta la app:
   ```
   python app.py
   ```

5. Abre http://127.0.0.1:5000/ en tu navegador.

¡Disfruta las flores amarillas danzantes! 💛❤️
